# Наталья Тополь-Сандр — Сайт-визитка

Сайт-визитка для Натальи Тополь-Сандр, коуча PCC ICF и супервизора EMCC, специалиста по межкультурной коммуникации.

## 🎨 Дизайн

Стиль **"Warm Editorial Luxury"** с теплой палитрой земных тонов, элегантной типографикой и плавными анимациями.

### Цвета
- **Cream**: #F5F0E8 (основной фон)
- **Sand**: #E8DFD0 (вторичный фон)
- **Dark Brown**: #3D2B1F (заголовки)
- **Terracotta**: #B5614A (акцент)
- **Gold**: #C4A265 (декоративные элементы)
- **Sage**: #7A8C7E (тайтлы)

### Шрифты
- **Cormorant Garamond** — заголовки (элегантность)
- **Montserrat** — текст (современность)

## 📁 Структура проекта

```
css/
├── variables.css      // CSS-переменные
├── base.css          // Сброс, типографика
├── layout.css        // Секции, сетки
├── components.css    // Компоненты
└── animations.css    // Анимации

js/
├── scroll.js         // Scroll Reveal
└── ui.js            // Интерактивность

images/
└── natalia.jpg      // Фото

index.html           // Главная страница
```
